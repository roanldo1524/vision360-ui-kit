# Las notas atómicas tienen una sola idea

> [!abstract] Una neurona = una idea, escrita con mis palabras.

Si una nota contiene dos ideas, no se puede conectar con precisión. Notas pequeñas → más conexiones posibles → más ideas emergentes.

## Sinapsis
- Es la base de [[El conocimiento crece por conexiones, no por acumulación]].
- Se aplica al procesar [[Captura rápida, procesamiento lento]].
